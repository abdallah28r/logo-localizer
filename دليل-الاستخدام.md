# Logo Localizer: user guide

A skill for **Codex** that translates logos and titles (games, films, series, anime, books, comics) from any language
into another in the same artistic style, with Arabic as the main target. It works on one logo per
request and draws with Codex's built-in tool (`image_gen`), which needs no API key.

## Installing in Codex

1. Delete the old copy if there is one: `%USERPROFILE%\.codex\skills\logo-localizer`
2. Copy the whole `logo-localizer` folder in its place.
3. Libraries (once): `python -m pip install -r requirements.txt`
4. Restart Codex.

## Example requests

- «عرّب الشعار في هذه الصورة بنفس أسلوبه» → the logo is replaced inside the image
- «اعمل نسخة عربية مستقلة من هذا الشعار» → a separate Arabic logo, the source as a style reference
- «ترجم شعار هذه اللعبة إلى الفرنسية» → another target language

**Any wording works.** «عرّب», «ترجم», «عرّب هذه الصورة», an image with no words, or calling the
skill alone (`$logo-localizer`) all mean "translate the logo in this image" (to Arabic unless you name
another language), and all start with the cards. Earlier tests showed that «عرّب هذه الصورة» could
make Codex draw right away; the skill now names it explicitly, but this has not been retested yet.

## What happens on every request

1. **It looks at the image** and marks the logo to translate; other text stays as it is unless you ask.
2. **Design analysis card:** the letter structure (measured), weight, rhythm, mood, surface, what it
   will do with each decoration (keep it / move it to a target letter / drop it), the general
   direction, and the visual anchors that must not be lost.
3. **Translation card:** it researches first, then writes its own options (as many as are really
   different); an official target-language title, if found, comes first and is marked. A
   recommendation, a space to type your own text, and a question about any subtitle or tagline in
   the logo (translate, keep, or drop).
4. **It stops and waits for you.** Nothing is drawn, and no file is created, before you choose or type
   a text (a letter from the card is enough).
5. **Spec and preflight:** it creates the job folder and `job.json` (regions, languages, approved
   text, four styles of its choosing, anchors, colours), checks it with `job_spec.py check`, and
   shows you a short summary.
6. **It draws four versions with Codex:** it first removes the old logo from the image (a clean
   plate), then draws the new logo **on a transparent background** in four different styles, one
   image each, and places each one where the old logo was, at about its size. You see four
   separate images, numbered 1 to 4, and reply with a number. Or you ask for four more: «أربع أخرى
   قريبة من الأصل» (new styles close to the original's spirit) or «أربع أكثر إبداعاً» (bolder styles
   that may move further from the original). The next batch is numbered 5 to 8, and so on; no
   number repeats, and you can still pick any earlier number.
7. **It checks only the one you picked:** a comparison sheet next to the original, a letter-by-letter
   table, a table of every spark or shard that could read as a dot (both by eye), a look at the
   transparent logo on dark, light and checkerboard, and a look at what was rebuilt behind the old
   logo. It lists every error
   found without fixing it.
8. **Your edits:** every further change is your decision: name it, and it edits that logo (after
   three stacked edits it asks whether to redraw from the original instead).
9. **Delivery:** the image in the original's format and size, the Arabic logo on its own with a
   transparent background, and a comparison sheet with the original.
10. **Save and clean up:** it asks where to save, and creates a new folder there with the three
    delivery files, the original image, and `job.json`. Then it shows you the list of working files
    (the plate, the layers, the numbered images you did not pick) and deletes them permanently only
    if you say yes. Your original file and the saved folder are never deleted.

## The references (how the skill thinks)

| File | Contents |
|---|---|
| `logo-localization.md` | The method: settling the title, breaking the logo into blocks, the signature letter, carrying decorations, checks |
| `text-design-transfer.md` | Carrying any lettering style into the target script: analysis, an Arabic style map (Kufi, Naskh, Ruqaa…), contrast, dots, kashida |
| `localization-rules.md` | Which texts are translated, protecting the rest of the image, size, masks and the clean plate |
| `codex-image.md` | How Codex's tool behaves, collecting its output, compositing |
| `visual-review.md` | The letter table, the mark table, the background inside the region, when to reject |

The references were built from research into the work of professional designers (29LT, Pentagram, the Khatt
Foundation, TypeTogether), real localization cases (Crunchyroll, Netflix, Ubisoft), and
academic studies on translating titles. The sources are listed at the end of each reference.

## The scripts (`scripts/`)

| Script | What it does |
|---|---|
| `init_job.py` | Creates the job folder and its `job.json` (`--mode localize` or `standalone`) |
| `job_spec.py` | Checks `job.json` and prints the preflight summary shown before any drawing |
| `codex_image.py` | `prompt` writes the prompt for Codex's tool from `job.json`, `collect` copies its output, `composite` builds the clean plate, `place` puts the transparent logo where the old one was |
| `make_mask.py` | The mask of the old logo for the clean plate (its ink, or its own colours) |
| `compare_sheet.py` | Comparison sheet next to the original (transparent logos also on dark, light and checkerboard) |

Tests: `python -m unittest discover -s tests`
