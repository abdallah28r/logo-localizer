# Logo Localizer: معرّب الشعارات

[English](README.md) · **العربية**

ترجم شعار أو عنوان لعبة أو فيلم أو مسلسل أو أنمي أو كتاب أو قصة مصورة إلى لغة أخرى **مع الحفاظ على أسلوبه الفني**. العربية هي الهدف الأول، وتعمل اللغات الأخرى أيضاً.

Logo Localizer مهارة لـ [Codex](https://github.com/openai/codex)، وكيل البرمجة من OpenAI. ترفق صورة وتختار النص، ثم يرسم Codex أربع نسخ لتختار منها.

## كيف تعمل

1. **أرفق صورة** واطلب الترجمة.
2. **أكّد الإذن.** يسألك Codex هل تملك الشعار أو لديك إذن من صاحب الحقوق. إذا أجبت بلا، يتوقف.
3. **اقرأ التحليل.** يدرس Codex الشعار ويبحث عن العنوان، ومنه أي ترجمة رسمية.
4. **اختر النص.** لا يُرسم شيء قبل أن تختار أحد الخيارات أو تكتب نصك.
5. **اختر التصميم.** تصلك أربع نسخ مرقّمة. اختر واحدة أو اطلب أربعاً أخرى.
6. **راجع الحروف.** يذكر Codex كل حرف أو نقطة أو لون خاطئ في النسخة التي اخترتها، ولا يغيّر إلا ما تطلبه.
7. **استلم ملفاتك:**
   - الصورة بصيغتها ومقاسها الأصليين
   - الشعار وحده بخلفية شفافة
   - مقارنة جنباً إلى جنب مع الأصل

## التثبيت

**تحتاج إلى:** [Codex](https://developers.openai.com/codex) مع أداته المدمجة `image_gen`، و[Python 3.11 أو أحدث](https://www.python.org/downloads/).

**الخطوة 1.** اطلب من Codex تثبيت المهارة. الصق هذا في Codex:

<div dir="ltr">

```text
Use $skill-installer to install the skill at the root of the GitHub repo abdallah28r/logo-localizer, with --path . and --name logo-localizer.
```

</div>

أو ثبّتها بنفسك عبر Git:

<div dir="ltr">

```bash
git clone https://github.com/abdallah28r/logo-localizer.git ~/.codex/skills/logo-localizer
```

</div>

في Windows PowerShell:

<div dir="ltr">

```powershell
git clone https://github.com/abdallah28r/logo-localizer.git "$HOME\.codex\skills\logo-localizer"
```

</div>

**الخطوة 2.** ثبّت مكتبتي Python:

<div dir="ltr">

```bash
python -m pip install -r ~/.codex/skills/logo-localizer/requirements.txt
```

</div>

في Windows PowerShell:

<div dir="ltr">

```powershell
python -m pip install -r "$HOME\.codex\skills\logo-localizer\requirements.txt"
```

</div>

**الخطوة 3.** أعد تشغيل Codex.

إذا لم تظهر المهارة في Codex، انقل المجلد إلى `~/.agents/skills/logo-localizer`، وهو موقع المستخدم المذكور في [توثيق مهارات Codex](https://developers.openai.com/codex/skills).

## الاستخدام

أرفق صورة واكتب مثلاً:

- `عرّب الشعار في هذه الصورة`
- `ترجم شعار هذه اللعبة إلى الفرنسية`
- `$logo-localizer` وحدها

اللغة الهدف هي العربية ما لم تذكر غيرها. كل طلب يعالج شعاراً واحداً.
